
# Campus Connect - Mobile App Wireframing

## Project Description
Campus Connect is a student management mobile application
designed to help students manage their academic activities.

## Key Features
- Student Dashboard
- Assignment Management
- Class Timetable
- Student Profile
- Simple Navigation

## Technologies Used
- HTML
- CSS
- JavaScript

## Design Process
1. Identify student requirements.
2. Understand student problems.
3. Create user personas.
4. Design user flows.
5. Create low-fidelity wireframes.
6. Test navigation and usability.

## Expected Outcome
A simple mobile application wireframe that demonstrates
the basic structure and navigation of a student app.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
